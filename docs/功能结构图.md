# 词力星球 · 产品功能结构图

> 面向小学 / 初中 / 高中三学段的背单词记录 App。学习产生数据 → 掌握度追踪 → 激励体系反哺学习动力，形成正向闭环。

## 一、功能模块总览

```
词力星球
├── 1. 核心学习模块
│   ├── 跟读
│   │   ├── 标准发音播放（Web Speech API · SpeechSynthesis）
│   │   ├── 录音跟读（SpeechRecognition）
│   │   └── 相似度评分 + 即时反馈（编辑距离算法）
│   ├── 拼写
│   │   ├── 听音拼写（播放发音 → 输入英文）
│   │   └── 看义拼写（显示中文释义 → 输入英文）
│   └── 中英考试
│       ├── 中译英（选择题）
│       ├── 英译中（选择题）
│       └── 混合测验（8 题 / 计时 / 逐题回顾）
├── 2. 激励体系
│   ├── 每日打卡（连续天数可视化，断签重置）
│   ├── 里程碑成就（累计 500 词 / 连续 30 天 等阶段目标解锁）
│   └── 积分系统（任务 + 高分换积分 → 兑换奖励 / 称号）
├── 3. 词汇掌握度追踪
│   ├── 熟练度计算（耗时 + 正确率综合 → 0~100%）
│   ├── 双重呈现（百分比数字 + 进度条长度）
│   └── 智能排序（列表按熟练度从低到高，优先薄弱词）
└── 4. 词汇内容
    ├── 高频词库（三学段，★ 标记高频等级 ★★★/★★/★）
    ├── 用法说明卡片
    └── 例句卡片（点击播放朗读）
```

## 二、页面原型（本仓库已实现可运行）

| 页面 | 路由 | 关键内容 |
|------|------|----------|
| 首页 | `home` | 称号 / 积分、每日打卡（7 天圆环）、快捷入口、里程碑墙 |
| 学习 | `learn` | 跟读 / 拼写切换、听音拼写 / 看义拼写、实时评分 |
| 考试 | `exam` | 学段 + 题型配置、选择题测验、正确率与积分结算 |
| 词卡 | `book` | 搜索 / 学段筛选、按熟练度排序、点击查看用法与例句 |
| 统计 | `stats` | ECharts：熟练度分布饼图 / 14 天打卡柱图 / 各学段掌握对比 |
| 结构图 | `map` | 本功能结构图的交互式呈现 |

## 三、数据闭环

```
练习/考试 ──recordResult──▶ word_mastery（熟练度）
        │                          │
        └──points / check_in──▶ 积分 / 连续打卡
                                  │
                           evaluateMilestones
                                  │
                          解锁里程碑 + 升级称号
                                  │
                         反哺学习动力（首页激励）
```

## 四、技术架构

- **前端**：React 18 + TypeScript + Vite + Tailwind CSS + ECharts
- **发音**：浏览器原生 Web Speech API（朗读 / 识别评分）
- **状态**：本地 `localStorage` 持久化（Demo），可平滑替换为后端接口
- **后端（可选）**：Node.js / FastAPI + SQLite / PostgreSQL，提供词库与进度同步
