# 核心功能关键实现说明

> 本仓库为可运行 Demo（React + TypeScript + Vite + Tailwind + ECharts），数据用 `localStorage` 持久化，与后端表结构（`docs/数据库设计.md`）字段一一对应。下面标注各能力对应的关键代码位置。

## 1. 跟读评分（Web Speech API）

- 朗读：`src/lib/speech.ts` 的 `speak()` 用 `SpeechSynthesis` 播放标准发音。
- 录音评分：`recognize(target, onPartial)` 用 `webkitSpeechRecognition` 实时识别，`similarity()` 用**编辑距离**计算与目标词的相似度（0~100）。
- 业务落点：`src/pages/Learn.tsx` 的 `startFollow()`，相似度 ≥ 70 记为正确并写入掌握度。

```ts
// src/lib/speech.ts（节选）
export function recognize(target: string, onPartial?: (t: string) => void): Promise<RecogResult> {
  const rec = new (window as any).webkitSpeechRecognition()
  rec.lang = 'en-US'; rec.interimResults = true
  // ... onresult 收集文本，onend 返回 similarity(target, transcript)
}
```

## 2. 拼写（听音 / 看义）

- `src/pages/Learn.tsx` 的 `submitSpell()`：比较输入与 `word.term`（忽略大小写/空格），正确写入掌握度。

## 3. 中英考试（测验）

- `src/pages/Exam.tsx`：配置学段与题型 → `buildQuestions()` 自动出题（正确答案 + 3 个干扰项）→ 逐题计时 → 结算时 `store.recordResult(..., 10)` 批量写入并结算积分。

## 4. 熟练度计算与追踪

- `src/lib/store.ts` 的 `recordResult()`：按正确率 + 耗时速度因子综合计算 0~100，更新 `word_mastery` 等价结构。
- 双重呈现：`src/components/common.tsx` 的 `ProficiencyBar`（百分比 + 进度条，颜色随区间变化）。
- 智能排序：`store.weakFirst()` 按熟练度从低到高返回，学习/词卡列表优先薄弱词。

## 5. 激励体系

- 打卡：`store.checkIn()` 计算连续天数（与前一天相差 1 天则 +1，否则重置），写入 `check_ins` 等价结构。
- 里程碑：`evaluateMilestones()` 依据 `target`（totalWords / streak / points / mastered）自动解锁并发奖励积分、升级称号。定义见 `src/data/milestones.ts`。
- 称号：按累计积分从 `TITLES` 中取最高档。

## 6. 统计可视化（ECharts）

- `src/components/EChart.tsx`：通用封装，初始化 + 自适应 resize + 卸载销毁。
- `src/pages/Stats.tsx`：熟练度分布饼图、近 14 天打卡柱图、各学段掌握对比柱图。

## 7. 词卡内容

- 词库：`src/data/words.ts`（三学段、★ 高频等级、用法、例句）。
- 词卡弹层：`src/components/WordCard.tsx` 展示音标、释义、用法说明、可朗读例句，并显示当前熟练度。

## 本地运行

```bash
npm install
npm run dev      # http://localhost:5173
# 或
npm run build && npm run preview
```

> 注：跟读语音识别依赖浏览器支持（推荐 Chrome / Edge）；发音朗读所有现代浏览器均支持。
